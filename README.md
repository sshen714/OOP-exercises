# OOP Exercises

這個儲存庫整理了物件導向程式設計課程的 C++ 作業與期中考練習。每個資料夾都是獨立的 CMake 專案；題目說明與檔案結構請參考各資料夾內的 README。

## 專案列表

| 專案 | 內容 |
| --- | --- |
| [Homework 01](OOP2026f_HW1/) | 機票與訂單，練習函式、`enum class`、`vector`。 |
| [Homework 02](OOP2026f_HW2/) | 書本與書架，練習類別、方法、容器與排序。 |
| [Homework 03](OOP2026f_HW3/) | 火車與車票，練習繼承與虛擬函式。 |
| [Midterm](2026F_Midterm/) | 薑餅人角色、不同屬性的餅乾與隊伍系統。 |
| [Midterm Resit](2026F_MidtermResit/) | 延伸薑餅人角色與隊伍系統的補考題。 |

## 專案結構

各專案主要包含 `include/` 標頭檔、`src/` 實作、`test/` 測試，以及 `CMakeLists.txt` 與 `files.cmake`。詳細需求與測試範圍以各專案的 README 為準。
